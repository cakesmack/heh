# Highland Events Hub frontend

This directory contains the Next.js Pages Router application written in TypeScript and styled with Tailwind CSS.

Use [the development setup guide](../docs/development/setup.md) for the supported dependency and environment contract. Frontend dependencies and commands are declared in [package.json](package.json); route entrypoints live under [src/pages/](src/pages/).

Start with the repository [documentation index](../docs/index.md) and [authoritative context](../events_hub_context.md) before changing application behaviour.
