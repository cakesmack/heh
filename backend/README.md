# Highland Events Hub backend

This directory contains the FastAPI, SQLModel/SQLAlchemy, PostgreSQL, and Alembic backend.

Use [the development setup guide](../docs/development/setup.md) for environment and safety requirements. Runtime dependencies are declared in [requirements.txt](requirements.txt); the isolated test environment uses [requirements-dev.txt](requirements-dev.txt), and the approved suite lives in [tests/](tests/).

Start with the repository [documentation index](../docs/index.md) and [authoritative context](../events_hub_context.md) before changing application or migration code.
